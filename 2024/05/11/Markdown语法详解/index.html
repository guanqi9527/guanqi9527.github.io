Markdown语法详解

Markdown 是一种轻量级标记语言，用来用纯文本快速书写格式化文档。以下为常用语法速查。

基础语法

  • 标题：# 到 ###### 对应 1~6 级标题。
  • 段落与换行：空行分段，行尾两个空格强制换行。
  • 加粗与斜体：**加粗**，*斜体*，***粗斜体***。
  • 引用：前缀 > 可多级嵌套。
  • 列表：无序 -、*、+；有序 1.、2.。
  • 分割线：---、*** 或 ___。

代码与高亮

  • 行内代码：用反引号包裹，如 `code`。
  • 代码块：三反引号包裹，可指定语言高亮：
列1 列2
A B
  • 已完成
  • 待处理

## 高级用法

- 脚注：`这是脚注[^1]`，末尾写 `[^1]: 说明文本`。
- 数学公式：在支持的渲染器中使用 `$...$` 或 `$$...$$`。
- 折叠块：部分博客主题支持 `<details><summary>标题</summary>内容</details>`。

## 写作建议

- 控制段落长度，避免过长句子。
- 标题层级有序，方便生成目录。
- 代码块标注语言，便于语法高亮。
- 使用引用和表格来强化信息结构。
