上传到 GitHub 的过程

面向初学者的 GitHub 上传流程，从创建仓库到推送代码，覆盖 HTTPS/SSH 配置与常见问题排查。

先决条件

  • 本地已安装 Git（git --version 验证）。
  • 有 GitHub 账号并已登录。
  • 本地项目目录已准备好。

步骤 1：在 GitHub 创建远程仓库

  1. 打开 https://github.com 点击右上角 New repository。
  2. 填写仓库名（尽量与项目目录一致），可选描述。
  3. 选择公开/私有。
  4. 是否初始化 README、.gitignore、license（如果本地已有，可不勾选）。
  5. 创建后停留在仓库页，记录仓库的 HTTPS 或 SSH 地址。

步骤 2：在本地初始化或关联仓库

在项目根目录执行：

  • 选择地址：初学者可用 HTTPS；熟练或自动化环境推荐 SSH。

步骤 3：配置身份

若使用 HTTPS

  • 建议创建 GitHub Personal Access Token（Settings → Developer settings → Tokens）。
  • 首次推送时用用户名 + token 作为密码。

若使用 SSH

  • 将公钥内容添加到 GitHub → Settings → SSH and GPG keys。

常见问题排查

  • 权限/认证失败：确认 token 未过期；SSH 检查 ssh -T git@github.com 输出；代理环境下注意代理配置。
  • remote already exists：git remote set-url origin <url> 更新；git remote -v 查看当前地址。
  • 大文件推送失败：清理或改用 Git LFS；单文件默认上限 100MB。
  • 忽略无效：确认 .gitignore 已提交；git status --ignored 查看被忽略文件。
  • 分支不一致：推送时提示需先拉取，可 git pull --rebase origin main 再推送，若远端为空可加 --force-with-lease。
